PET-Saúde Digital — Banner responsivo

Arquivos:
- index.html: página responsiva para celular e computador.
- banner.jpg: banner utilizado pela página.

Publicação:
1. Crie um repositório no GitHub.
2. Envie index.html e banner.jpg para o repositório.
3. Ative GitHub Pages em Settings > Pages.
4. Selecione Deploy from a branch, escolha a branch principal e a pasta / (root).
5. O GitHub fornecerá uma URL terminada em github.io.
6. Gere o QR Code apontando para essa URL.

O layout foi preparado para:
- celular: banner ocupa 100% da largura;
- computador: banner fica centralizado, com largura máxima de 1080 px;
- tablets: adaptação automática;
- impressão: remove margens e sombra.
- Atualização do projeto.
